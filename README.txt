Shade - hide apps & games (Android launcher)
1. Install Android Studio, then File > Open > select this folder (ShadeAndroid).
2. Wait for Gradle sync, connect a phone (USB debugging on) and press Run.
3. Press the Home button, choose "Shade" > "Always" to make it your home screen.
4. Long-press an app to hide it. Tap "Vault" + PIN to see hidden apps.
Build > Build APK(s) creates an installable APK.
